Advanced

45 ms
Cursor look-ahead that hides camera latency. 0 = pure smoothing. Lower it if you feel it overshooting.
12 px
How far a held click moves before it becomes a drag. Raise it if drags start by accident; lower it for snappier dragging.
0.003
Hand wobble below this never scrolls. Raise it if the page scrolls on its own.
2.5 px
Kills rest jitter: a still hand holds the cursor rock-steady, and the hold fades out as you move faster so quick motion keeps zero lag. 0 = off.
4%
Cursor pauses when the aim point enters this frame border — that's where tracking jitters. 0 disables the hold.

Sonar — experimental

Hand sensing via speaker + mic
Emits an inaudible tone and listens for Doppler echoes from your hand — sensing only, it never moves the cursor
Higher is quieter to the ear but some speakers roll off hard above 17 kHz. If motion never lights up, drop to 17 kHz.
Use built-in laptop speakers/mic for the sonar effect — headphones won't reflect the tone.

System

Start control on launch

Switches live — the feed restarts on the new camera within a second.
If the camera only gives ~10 new frames/s in dim light, turn off low-light compensation / dynamic frame rate in this dialog (or just add light).
Switches live in about a second. The list holds the bundled model plus every imported MediaPipe .task hand model; imports are validated before they are accepted.
Auto runs the hand models on your GPU (~10× faster inference, much less CPU). Falls back to the CPU engine automatically. Switches live in about a second; custom models and 2-hand mode use the CPU engine.
The frame the tracker analyses (downscaled in software from the camera's native mode — no cropping). Applies within a second.
60 fps halves the camera latency and smooths fast moves. Needs a camera that supports 720p60 (most do); otherwise it stays at 30.
Every extra hand costs ~7 ms of inference per frame. One hand is all the cursor needs.
Refresh app restarts the camera, model and overlay in place — use it if anything gets stuck. Diagnostics = fps, inference, pinch stats and emitter health for troubleshooting.
